此任务需要人工验证 MicroVM 的实际启动和运行。

**验证步骤：**

1. 启动 MicroVM 服务：
   ```bash
   sudo systemctl start microvm-openclaw
   ```

2. 观察启动日志（等待 30-60 秒）：
   ```bash
   journalctl -u microvm-openclaw -f
   ```

   期望输出：
   - virtiofsd 服务启动成功
   - cloud-hypervisor 启动
   - NixOS guest 开始引导
   -  systemd 在 guest 内启动

3. 测试 console 访问：
   ```bash
   sudo microvm-console openclaw
   ```

   期望行为：
   - 成功连接到 guest 控制台
   - 可以看到 guest 的登录提示
   - 可以输入命令（guest 无密码配置）

4. 在 guest 内验证基本功能：
   ```bash
   # 在 microvm-console 中执行
   cat /etc/os-release
   hostname
   ```

5. 退出 console（Ctrl+] 或输入 exit）

6. 停止 MicroVM（测试优雅关闭）：
   ```bash
   sudo systemctl stop microvm-openclaw
   ```

**验证完成后，输入 "approved" 或描述遇到的问题。**
