```nix
sops.secrets = {
  # ... 现有 secureboot 密钥 ...

  # OH-03: OpenHands LLM API 密钥
  openhands_llm_api_key = {
    sopsFile = ./secrets/openhands.yaml;
    key = "LLM_API_KEY";
    # 关键：显式指定路径以匹配容器 bindMount 和 systemd EnvironmentFile
    # 容器 bindMount: /run/secrets/openhands (目录)
    # systemd EnvironmentFile: /run/secrets/openhands/LLM_API_KEY (文件)
    path = "/run/secrets/openhands/LLM_API_KEY";
    owner = "root";
    mode = "0400";
  };
};
```

关键配置说明：
- sopsFile: 密钥文件路径，相对于 nixos/ 目录
- key: YAML 文件中的键名
- **path: 显式指定密钥解密后的存放路径**
  - 必须与 Plan 01 中的 bindMount 目录和 EnvironmentFile 路径匹配
  - bindMount 挂载 `/run/secrets/openhands` 目录
  - systemd 读取 `/run/secrets/openhands/LLM_API_KEY` 文件
- owner: root 用户拥有解密后的密钥
- mode: 0400 仅 root 可读

- YAML 格式：`LLM_API_KEY: "sk-xxx"`

- 确保密钥名称 `LLM_API_KEY` 与 sops.secrets 中的 `key` 配置一致
