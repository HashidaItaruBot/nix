  <action>
在 `nixos/sops.nix` 的 `sops.secrets` 块中添加 OpenHands 密钥配置：

```nix
sops.secrets = {
  # ... 现有 Secure Boot 密钥 ...

  # OpenHands LLM API 密钥
  openhands_llm_api_key = {
    file = "/var/lib/openhands/.env";
    format = "env";
    sopsFile = ${self}/shared/secrets/openhands.yaml;
    owner = "root";
    group = "root";
    mode = "0400";
  };
};
```

注意：
- 使用 format = "env" 生成 KEY=VALUE 格式
- 密钥文件解密到 /var/lib/openhands/.env
- 权限设置为 0400 仅 root 可读
