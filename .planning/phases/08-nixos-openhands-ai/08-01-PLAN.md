```nix
{ config, pkgs, self, ... }:
{
  # OpenHands NixOS Container Configuration
  # 架构：nixos-container (外层隔离) + Docker (容器内运行)
  # 参考：CONTEXT.md 架构决策

  containers.openhands = {
    # OH-05: 开机自启
    autoStart = true;

    # 网络配置：NAT 模式
    privateNetwork = true;
    hostBridge = null;  # NAT mode

    # OH-02: 端口转发 (宿主机 3000 -> 容器 3000)
    forwardPorts = [{
      containerPort = 3000;
      hostPort = 3000;
      protocol = "tcp";
    }];

    # OH-04: 数据持久化 bind mount
    bindMounts = {
      "/var/lib/openhands" = {
        hostPath = "/var/lib/openhands";
        isReadOnly = false;
      };
      # SOPS 密钥挂载 (Plan 02 配置)
      # 密钥路径: /run/secrets/openhands/LLM_API_KEY
      "/run/secrets/openhands" = {
        hostPath = "/run/secrets/openhands";
        isReadOnly = true;
      };
    };

    # 容器内配置
    config = { config, pkgs, ... }: {
      # OH-01: Docker 运行时
      virtualisation.docker.enable = true;

      # 网络配置
      networking.firewall.allowedTCPPorts = [ 3000 ];

      # OpenHands 服务 (Docker Compose)
      systemd.services.openhands = {
        description = "OpenHands AI Programming Assistant";
        wantedBy = [ "multi-user.target" ];
        after = [ "docker.service" ];
        requires = [ "docker.service" ];

        serviceConfig = {
          Type = "oneshot";
          RemainAfterExit = true;
          WorkingDirectory = "/var/lib/openhands";
          ExecStart = "${pkgs.docker-compose}/bin/docker-compose up -d";
          ExecStop = "${pkgs.docker-compose}/bin/docker-compose down";
          # 从 SOPS secret 文件读取 LLM_API_KEY
          EnvironmentFile = "/run/secrets/openhands/LLM_API_KEY";
        };

        # LLM 配置 (阿里百炼 OpenAI 兼容)
        environment = {
          LLM_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1";
          LLM_MODEL = "qwen-plus";
          # LLM_API_KEY 通过 EnvironmentFile 注入，格式: LLM_API_KEY=sk-xxx
        };
      };

      # 系统包
      environment.systemPackages = with pkgs; [
        docker-compose
      ];
    };
  };

  # 宿主机上创建数据目录
  systemd.tmpfiles.rules = [
    "d /var/lib/openhands 0755 root root -"
    "d /var/lib/openhands/data 0755 root root -"
    "d /var/lib/openhands/workspace 0755 root root -"
    "d /run/secrets/openhands 0755 root root -"
  ];
}
```

关键实现要点：
- autoStart = true 满足 OH-05 (开机自启)
- forwardPorts 配置满足 OH-02 (端口 3000 可访问)
- bindMounts 配置满足 OH-04 (数据持久化)
- virtualisation.docker.enable 满足 OH-01 (Docker 运行时)
- 使用阿里百炼 LLM 后端 (OpenAI 兼容 API)
- **重要修复:** 使用 EnvironmentFile 从 SOPS secret 文件读取 LLM_API_KEY
  - Secret 文件路径: `/run/secrets/openhands/LLM_API_KEY`
  - Secret 文件格式: `LLM_API_KEY=sk-xxx` (Plan 02 创建)
  - systemd EnvironmentFile 会自动将文件中的变量注入环境
  - docker-compose.yml 通过 `${LLM_API_KEY}` 引用此变量

根据 CONTEXT.md 中的配置创建 `nixos/containers/docker-compose.yml`：

```yaml
# OpenHands Docker Compose Configuration
# 部署在 nixos-container 内部
# 数据路径：/var/lib/openhands (宿主机 bind mount)

services:
  openhands:
    image: ghcr.io/all-hands-ai/openhands:latest
    container_name: openhands
    ports:
      - "3000:3000"
    volumes:
      # Docker socket - 允许 OpenHands 创建沙箱容器
      - /var/run/docker.sock:/var/run/docker.sock
      # 数据持久化
      - ./data:/.openhands
      # 工作空间
      - ./workspace:/opt/workspace_base
    environment:
      # LLM 配置 - 阿里百炼 (OpenAI 兼容)
      - LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
      - LLM_API_KEY=${LLM_API_KEY}
      - LLM_MODEL=qwen-plus
      # 沙箱运行时镜像
      - SANDBOX_RUNTIME_CONTAINER_IMAGE=docker.all-hands-ai.com/all-hands-ai/runtime:0.35
    restart: unless-stopped
    # 资源限制 (4GB RAM)
    deploy:
      resources:
        limits:
          memory: 4G
        reservations:
          memory: 2G
```

关键配置说明：
- 使用官方 OpenHands 镜像 ghcr.io/all-hands-ai/openhands:latest
- 挂载 Docker socket 用于创建沙箱容器 (OpenHands 核心功能)
- 配置阿里百炼作为 LLM 后端 (qwen-plus 模型)
- LLM_API_KEY 通过环境变量注入 (来自 systemd EnvironmentFile)
- 设置 4GB 内存限制
