使用 home-manager 的 services.colima 模块（推荐）：
```nix
{ pkgs, config, ... }:
{
  services.colima = {
    enable = true;
    autoStart = true;
    settings = {
      memory = 8;  # GB
      cpu = 4;
      disk = 100;  # GB
    };
  };
}
```

如果 services.colima 不可用，使用 launchd agent 备选方案：
```nix
{ pkgs, config, ... }:
{
  launchd.user.agents.colima-start = {
    command = "${pkgs.colima}/bin/colima start --memory 8 --cpu 4 --disk 100";
    serviceConfig = {
      RunAtLoad = true;
      KeepAlive = false;
      StandardOutPath = "/tmp/colima-start.log";
      StandardErrorPath = "/tmp/colima-start.err";
    };
  };
}
```

2. 资源配置固定为：memory=8, cpu=4, disk=100
3. autoStart=true 实现登录时自动启动
