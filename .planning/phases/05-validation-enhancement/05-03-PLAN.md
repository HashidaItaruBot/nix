  <action>
Create `.github/workflows/ci.yml` with a multi-platform CI pipeline.

The workflow should:

1. **Triggers**: Run on push to `main` and on pull requests
2. **Matrix**: Run on both `ubuntu-latest` (for x86_64-linux) and `macos-latest` (for aarch64-darwin)
3. **Steps**:
   - Checkout code
   - Install Nix using `cachix/install-nix-action@v27`
   - Run `nix flake check --no-build` (validates flake structure)
   - Run `nix run nixpkgs#alejandra -- --check .` (formatting check)
   - Run `nix run nixpkgs#statix -- check .` (linting)

Use the following structure:

```yaml
name: Nix CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  check:
    strategy:
      matrix:
        include:
          - os: ubuntu-latest
            system: x86_64-linux
          - os: macos-latest
            system: aarch64-darwin
    runs-on: ${{ matrix.os }}

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Install Nix
        uses: cachix/install-nix-action@v27
        with:
          nix_path: nixpkgs=channel:nixpkgs-unstable
          extra_nix_config: |
            experimental-features = nix-command flakes

      - name: Check flake validity
        run: nix flake check --no-build --system ${{ matrix.system }}

      - name: Check Nix formatting
        run: nix run nixpkgs#alejandra -- --check .

      - name: Run statix linter
        run: nix run nixpkgs#statix -- check .
```

Do NOT add binary cache (cachix/attic) - deferred per user decision.
Do NOT add secrets validation script to CI - that requires local hardware access.
