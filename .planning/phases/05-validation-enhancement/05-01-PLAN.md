<task type="auto">
  <name>Task 1: Create secret validation script</name>
  <files>scripts/verify-secrets.sh</files>
  <action>
Create `scripts/verify-secrets.sh` that verifies no secrets are leaked to the nix store.

The script should:
1. Check for SOPS markers (`ENC[`) in /nix/store paths
2. Check for age encryption markers (`age1`) in yaml files in /nix/store
3. Exit with code 1 if secrets are found, 0 if clean
4. Print clear success/failure messages
5. Be executable (include shebang `#!/usr/bin/env bash`)

Use `set -euo pipefail` for strict mode. Redirect stderr to /dev/null for grep commands to avoid permission noise.

Do NOT search the entire /nix/store recursively (too slow) - instead check recent derivations or use targeted patterns. A simpler approach: check for the specific patterns in any readable /nix/store paths.
  </action>
  <verify>
    <automated>test -x scripts/verify-secrets.sh && bash scripts/verify-secrets.sh</automated>
  </verify>
  <done>Script exists, is executable, runs without error, and reports "OK: No secrets found in /nix/store"</done>
</task>
