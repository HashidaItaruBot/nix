  <files>nixos/home/git.nix</files>

  <action>
    Research indicates ssh-keygen -Y sign uses the public key file path (~/.ssh/id_ed25519.pub) passed by git.
    However, when using SSH agent forwarding, the private key is NOT stored as a file - it's only available via SSH_AUTH_SOCK.

    The key insight from 02.1-RESEARCH.md:
    - git passes the signing.key value to ssh-keygen -Y sign as the -f parameter
    - ssh-keygen checks if the private key is available in SSH_AUTH_SOCK
    - If found, signing proceeds using the agent

    Add home.file.".ssh/id_ed25519.pub" to nixos/home/git.nix with the public key content:
    ```nix
    home.file.".ssh/id_ed25519.pub".text = "ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIP5M2RGhIG1CslAdzx+1xcOFiAgJhw0FKFqhe/Wkm1qZ";
    ```

    This ensures ssh-keygen -Y sign -f ~/.ssh/id_ed25519.pub can find the public key file,
    then locate the matching private key in SSH_AUTH_SOCK.
  </action>
  <verify>
    <automated>nix eval .#nixos.home-manager.users.zhaochanglong.home.file.".ssh/id_ed25519.pub" 2>&1 | grep -q "ssh-ed25519" && echo "pubkey file OK" || echo "pubkey file MISSING"</automated>
  </verify>
  <done>
    ~/.ssh/id_ed25519.pub file created via home-manager with the correct public key content.
    ssh-keygen can now find the public key file and match it to the private key in SSH agent.
  </done>
