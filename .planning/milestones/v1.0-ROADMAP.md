# Milestone v1.0: SSH Agent Forwarding 配置

**Status:** ✅ SHIPPED 2026-03-19
**Phases:** 1-3
**Total Plans:** 4

## Overview

为 macOS 配置 SSH agent forwarding，使其通过 SSH 连接到 NixOS 时能够使用本地 1Password 的 SSH 密钥。让 NixOS 上的 git 操作（push/pull/commit 签名）能够无缝使用 macOS 上的 1Password SSH 密钥。

## Phases

### Phase 1: SSH 配置

**Goal**: 配置 SSH 服务端和客户端支持 Agent Forwarding

**Depends on**: None

**Plans**: 2 plans

Plans:

- [x] 01-01: NixOS sshd 启用 AllowAgentForwarding
- [x] 01-02: macOS SSH 配置 ForwardAgent for nixos

**Details:**

NixOS SSH 服务器启用 AllowAgentForwarding，macOS SSH 客户端为 nixos 主机配置 ForwardAgent=true。

### Phase 2: Git 签名配置

**Goal**: 配置 NixOS git 使用转发的 SSH agent 进行签名

**Depends on**: Phase 1

**Plans**: 1 plan

Plans:

- [x] 02-01: 配置 git signer 使用 ssh-keygen

**Details:**

将 NixOS git signer 从 op-ssh-sign 改为 ssh-keygen，使其能够使用转发的 SSH agent 进行 commit 签名。

### Phase 3: 验证

**Goal**: 确保所有功能正常工作

**Depends on**: Phase 2

**Plans**: 1 plan

**Details:**

## Milestone Summary

**Key Decisions:**

- 使用 SSH Agent Forwarding 而非在 NixOS 上运行 1Password（1Password 仅支持 macOS）
- 使用 ssh-keygen -Y sign 代替 op-ssh-sign（ssh-keygen 支持 SSH agent forwarding）
- NixOS SSH 配置不设置 IdentityAgent，使用默认的 $SSH_AUTH_SOCK（从 macOS 转发）
- 平台特定的 git signer 配置放在 nixos/home/git.nix 中

**Issues Resolved:**

- 修复 NixOS SSH 配置中硬编码的 1Password IdentityAgent 路径
- 修复用户 ~/.ssh/config 中的错误 IdentityAgent 配置
- 添加 gpg.ssh.allowedSignersFile 配置使 git verify-commit 工作

**Technical Debt Incurred:**
